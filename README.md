**Selected work**

- **[AI Idea Prioritizer](https://github.com/KursadPlbyk/ai-idea-prioritizer):** LLM-based scoring tool where the Claude API rates ideas against a fixed rubric and a transparent formula computes the ranking. Pydantic-validated outputs, pytest-covered core. Prompt v2 raised impact discrimination from 0.46 to 0.78 and passed 15/15 edge cases, including a prompt-injection attempt.
- **[Japanese Handwriting Recognition](https://github.com/KursadPlbyk/japanese-handwriting-recognition):** 3-layer CNN in PyTorch classifying 95 handwritten Japanese characters (hiragana and historical kanji) with 97.71% test accuracy.
- **[UFC Fight Predictor](https://github.com/KursadPlbyk/ufc-fight-predictor):** end-to-end ML pipeline with 20 engineered features, reaching 71.8% test accuracy with a RandomForest (vs. 70.1% XGBoost and a 50% baseline).
- **[Japanese Audio Reader](https://github.com/KursadPlbyk/JapaneseAudioReader):** speech-to-text pipeline that turns Japanese audio into an interactive reader with furigana and sentence-by-sentence translation. Provider-agnostic backends (local Whisper, OpenAI API, DeepL).
